# C. Recommandations, classées par impact sur l'expérience

Version **dca39641**. Chaque ligne reprend un défaut significatif constaté sur capture (planches dans `captures/`).

**Classement** : l'ordre tient compte de trois choses :
- le nombre de personnes touchées (le propriétaire, client payant, d'abord) ;
- la fréquence de l'écran ;
- la gravité de la gêne.

**Priorités** :
- **P1** : important avant de lancer l'acquisition ;
- **P2** : souhaitable ;
- **P3** : finition.

Aucune recommandation ne touche à l'identité visuelle : elles retirent, regroupent ou renomment.
