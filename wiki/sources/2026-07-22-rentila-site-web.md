# Rentila — site web (concurrent)

**Source :** deux extraits du site <https://www.rentila.com/> (accueil + page « Avantages »),
déposés dans `raw/assets/`. Complétés par recherche web (tarifs, périmètre).

## Résumé
Rentila est un logiciel de gestion locative en ligne pour **bailleurs particuliers en
gestion directe** (particuliers, SCI, indivisions). Positionnement : « les moins chers » —
**gratuit pour 1 bien**, puis ~**49 €/an** pour 2–5 biens (recherche web). Noté 4,8/5
(1000+ avis). Fonctionnalités enrichies par l'IA (revendication marketing).

## Périmètre fonctionnel (revendiqué)
- Biens, locataires, **contrats de location** (conformes ALUR), **colocations**.
- **États des lieux**, **quittances automatiques**, suivi des loyers, **relances impayés**.
- **Comptabilité locative** + revenus fonciers + **aide à la déclaration fiscale**.
- **Régularisation des charges locatives** ; archivage de documents ; multi-entités/sociétés.
- **Accès locataire** ; messagerie propriétaire-locataire ; **suivi des demandes de réparations** ;
  synchronisation bancaire ; application mobile.
