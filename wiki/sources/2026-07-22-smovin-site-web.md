# Smovin — site web (concurrent)

**Source :** deux extraits du site <https://www.smovin.app/> (accueil FR-BE + page
« Gestion des contrats »), déposés dans `raw/assets/`. Complétés par recherche web.

## Résumé
Smovin est un logiciel de gestion locative **belge** (aussi décliné pour la France) visant
les **investisseurs/propriétaires** et petites structures ; références pro (Deloitte,
Century 21). Cœur de valeur : **le contrat de bail comme objet central** — le logiciel en
déduit automatiquement les actions à mener (échéances, indexations, fins de bail, breaks).

## Périmètre fonctionnel (revendiqué)
- **Contrats/baux riches**, y compris complexes : baux commerciaux, pop-up stores,
  cohabitations, bureaux ; loyers progressifs, gratuités, ruptures anticipées.
- **Suivi automatique des paiements entrants** (vérification bancaire) + rappels.
- **Indexation automatique des loyers** (formule légale IRL / ILC / ILAT).
- Avis d'échéance et quittances automatiques ; **décompte/refacturation des charges**.
- Communications locataires, tâches, tableaux de bord, rapports, **intégration comptable**, TVA.
- Tarifs : 4 formules **par nombre de lots**, sur mesure au-delà de ~30 biens.
