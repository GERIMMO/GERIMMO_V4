# GERIMMO V3 — Module 12 : Documents et GED

**En une phrase :** 5 parcours, 2 objets (**Document**, **Modèle**) — « ce module ne
produit rien, il organise » : lieu commun, droits d'accès et durées de conservation
pour tous les documents des modules 0 à 11. **Module clos.**

## Affirmations clés

1. **Aucune arborescence — décision actée** : un document est **rattaché à toutes les
   entités qu'il concerne** (bail → lot + locataire + propriétaire + mandat) et
   apparaît sur toutes leurs fiches ; **le TYPE pilote droits, conservation et
   affichage** (jamais l'emplacement). Navigation **par filtres et recherche**
   (RM-12.5.1), consultation **tracée** (RM-12.5.8).
2. **Modèles figés, générés par le super admin** (RM-12.1.1/4, décision actée — pas
   d'éditeur libre : « une mention manquante rend l'acte contestable ») : modèles
   Gerimmo fournis par défaut (14 types) ; une agence voulant son modèle le **soumet
   au SA** qui vérifie les mentions, identifie les variables de fusion et le génère
   (ou refuse motivé). Évolution réglementaire = mise à jour centrale pour toutes.
   Modèles **datés**, un document **conserve la version du modèle utilisée**
   (RM-12.1.5/6 = RM-1.16.2/3).
3. **Mise à disposition ≠ envoi** : mise à disposition = visible dans l'espace
   (locataire, artisan ; date de 1ʳᵉ consultation enregistrée) ; envoi = email /
   WhatsApp (date + canal tracés). **Le mandant ne reçoit que par envoi**
   (RM-12.4.2) ; recommandé tracé manuellement (RM-12.4.3). **La trace GED sert le
   suivi, jamais la preuve** (RM-12.4.4 = RM-A3.2, corrigé suite à l'audit P0.4) ;
   pour un acte juridique l'agent saisit la **date de première présentation**
   (RM-12.4.5). Envoi groupé (quittances du mois) ; document à signer → module 13.
4. **Matrice de consultation par type** : le locataire voit ses documents (bail, EDL,
   quittances, régularisations, ses devis à charge) ; l'artisan les siens ; **le
   mandant « reçoit » ou « sur demande », jamais les pièces du dossier locataire**
   (RM-12.5.5 = RM-0b.7.4).
5. **Conservation par type** : pièces du dossier 5 ans (0b) ; comptable, quittances,
   rapports, devis/factures **10 ans** ; **baux, avenants, EDL, mandats : sans
   limite** (preuve contractuelle) ; diagnostics tant que le bien est géré. La purge
   0b **ne touche ni le contractuel ni le comptable** (RM-12.5.7) ; un document purgé
   affiche « purgé le [date] » avec motif.

## Décisions actées / reports

Actées : modèles figés SA, pas d'arborescence, rattachement multiple, type pilote
tout, durées par type, trace ≠ preuve (audit P0.4). **Hors périmètre** : éditeur de
modèles agence, archivage à valeur probante certifié. 5 US, 7 critères.

## Ce que ce module dessert

Modules 0–11 (dépôt des documents), module 13 (documents à signer), module 15
(pièces jointes), module 17 (charte appliquée à la génération).
