# GERIMMO V3 — Module 17 : Marque blanche

**En une phrase :** 3 parcours, 1 objet (**Charte**) — un module d'**habillage**
(« aucun parcours métier n'est modifié ») : logo + deux couleurs de l'agence sur les
espaces, documents et emails. « Peu profond techniquement, décisif commercialement »
(vente aux réseaux). **Module clos.**

## Affirmations clés

1. **Trois décisions actées** : personnalisation limitée à **logo + couleurs** (pas de
   nom de domaine propre en V1 — DNS/TLS/SPF par agence = support ingérable pour un
   gain cosmétique) ; **la mention Gerimmo reste visible** en pied de page
   (RM-17.2.6, non supprimable) ; **c'est l'admin agence qui personnalise**
   (RM-17.2.1), le super admin ne fait qu'activer l'option (selon le plan).
2. **Contraintes techniques** : logo PNG/SVG fond transparent < 500 Ko ; **contrôle de
   contraste en alerte non bloquante** (« l'agence reste maîtresse de son
   identité ») ; prévisualisation ; application immédiate ; retour à la charte
   Gerimmo en un clic.
3. **Où la charte s'applique** : espaces locataire/artisan/agent, **documents générés**
   (logo + couleurs injectés à la génération — **la structure des modèles figés ne
   change jamais**, RM-17.2.4 = RM-12.1.1), emails, écran de connexion.
4. **Artisan multi-agences** : il voit la charte de l'agence consultée ; dans son
   agenda consolidé, **chaque ligne porte le logo de l'agence concernée** (RM-17.3.2).

## Décisions actées / reports

Actées : logo + couleurs, mention visible, personnalisation par l'AA.
**Abandonné** : personnalisation du bot WhatsApp (trop complexe). **V2** : nom de
domaine personnalisé. **Hors périmètre** : suppression de la mention, personnalisation
des libellés/parcours. 3 US, 5 critères.
